CENTURIA ATHLETICS v13.00 — НАГОРОДИ БЕЗ ЗАЙВОГО ПЕРЕМИКАЧА

ВСТАНОВЛЕННЯ
Замінити у корені сайту 3 файли поверх версії v12.99:
  app.js
  index.html
  service-worker.js

ЩО ЗМІНЕНО
1. Розділ «Статистика» → 4-й екран «НАГОРОДИ»: прибрано перемикач
   «ОФІЦІЙНІ МАТЧІ / ТРЕНУВАННЯ».
2. Нагороди за місяць і далі рахуються за усіма матчами разом (v12.98).
3. На інших екранах («Гравці команди», «Серії», «Рекорди»,
   «Порівняння») перемикач залишається і працює як раніше.
4. Перегортання свайпом і кнопками відновлює перемикач при виході
   з розділу нагород.
5. Збільшено номер версії та оновлено PWA-кеш.

НЕ ЗМІНЮВАЛОСЯ
— Підрахунок будь-яких нагород і пороги участі.
— Збережені нагороди та статистика у Supabase.
— Окрема статистика офіційних матчів та тренувань.

Після публікації онови сторінку/PWA, щоб підтягнувся новий app.js.

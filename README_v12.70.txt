Centuria v12.70 — календар: тренування, матчі Кубка й матчі Ліги

1. Виконай у Supabase SQL Editor SUPABASE_v12.70_CALENDAR_MATCH_TYPES.sql. Він додає image_url для емблем ліг і match_kind для типу матчу.
2. Заміни на сайті index.html, app.js, arena.js і style.css файлами з ZIP.
3. Натисни день у календарі: обери «Тренування», «Матч Кубка» або «Матч Ліги».
4. Після матчу відкрий цей день і натисни матч. Рахунок можна внести або змінити кнопкою «ВНЕСТИ / ЗМІНИТИ РАХУНОК»; поле доступне також під час редагування матчу.

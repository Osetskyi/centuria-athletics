CENTURIA ATHLETICS — SITE v1

Як запустити:
1. Розпакуй ZIP.
2. Відкрий index.html у Chrome або Edge.
3. При першому кліку браузер дозволить запустити фонову музику.

Що вже працює:
- Головний екран на основі затвердженого зображення.
- Клікабельні Гравці / Тактика / Склади / Налаштування.
- Нижня навігація.
- Додавання гравця з готовою карткою-зображенням.
- Нік, номер, основна позиція, до 3 додаткових позицій, архетип, примітка.
- Архетипи з узгодженого списку.
- Фільтри гравців.
- Тактики 4-5-1 (2 ЦАП, 1 ЦП) та 3-4-2-1 (2 ЦАП).
- Основна позиція = зелена плашка; додаткова = помаранчева; чужа = червона.
- Вибір будь-якого гравця на будь-який слот.
- Збереження розстановки як готового зображення.
- Вкладка «Склади» з назвою, схемою, датою і часом.
- Перегляд / перейменування / видалення / завантаження фото складу.
- Налаштування мови з жартівливими повідомленнями.
- Очищення всіх гравців або всіх складів.
- Автор: Daniil Osetskyi.
- Фонова музика, вимикач і гучність.
- Дані гравців та фото зберігаються у IndexedDB браузера.

Примітка:
Це локальна версія. Пізніше її можна викласти в інтернет і зробити PWA, щоб встановлювати на телефон як застосунок.

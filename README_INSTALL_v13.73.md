# Centuria Athletics — v13.73 Arena league archive restore

The Arena History screen now opens on the most recently completed archive, so an old saved Cup selection cannot hide a newer League. During the current visit, selecting League or Cup remains respected.

The completed League is already present in the shared Arena archive with 18 rounds and 72 scored matches. EVO is calculated from active competition results and archived competition results; closing the League moves those same matches into the archive without counting them twice, so the rating should remain consistent. Analytics Center files are not changed.

## Apply

Replace `index.html` and `arena.js` on the site, then reopen the installed site/PWA.

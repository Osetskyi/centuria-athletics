# Centuria Athletics — v13.72 Arena archive tab fix

Arena now remembers the History category selected by the user. If no category has been selected yet, it opens the most recently completed competition type. Closing a league/cup saves its History category so it remains selected after reopening the Arena or reloading the app. This patch does not change archive data or Analytics Center files.

## Apply

Replace `index.html` and `arena.js` on the site. Then reopen the installed site/PWA.

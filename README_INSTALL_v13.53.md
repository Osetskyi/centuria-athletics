# Centuria Test — full update v13.53

This is a complete site archive based on Centuria Test. It is not the main-site project.

## Install

Extract the archive and upload its contents to the Centuria Test project root, replacing files with the same names. Preserve the existing folder structure.

The current Analytics Center loads `analytics-center-v1348.css` and `analytics-league-v1348.js`. The dark and light backgrounds loaded by the page are `analytics-bg-dark-v1317.mp4` and `analytics-bg-light-v1317.mp4`. Older copies of the Analytics Center scripts and styles have been removed.

Settings displays version **v13.53**. No database migration is needed.

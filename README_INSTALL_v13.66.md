# Centuria Athletics — v13.66 Arena close-flow patch

Arena-only patch based on v13.65. Completing a league or cup clears the active Arena event, keeps the finished competition in the shared archive, and returns to the Arena home screen. The last-used History category remains selected when History is opened.

## Apply

1. Extract this patch over the site's current v13.65 files.
2. Replace only `index.html` and `arena.js`.
3. Leave all other files and all Analytics Center data as they are. This patch contains no Analytics Center scripts, styles, SQL, or data changes.

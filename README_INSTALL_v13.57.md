# Centuria Test — full update v13.57

This is a complete site archive based on Centuria Test. It is not the main-site project.

## Install

Extract the archive and upload its contents to the Centuria Test project root, replacing files with the same names. Preserve the existing folder structure.

The Analytics Center has separate League and Cup views. Cup matches are shown in a connected knockout bracket with one column per round, winner placeholders for later rounds, and horizontal scrolling on mobile. Admins can add matches and edit saved scores from the bracket cards. The Cup summary and collapsible participant list remain available.

No database migration is required for this update. The already-applied `SUPABASE_v1355_DOUBLE_FORFEIT.sql` migration remains part of the site history.

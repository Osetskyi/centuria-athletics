Centuria Athletics v13.86 — додавання гравців до Кубка без перетягування жеребу

У корені репозиторію Osetskyi/centuria-athletics замініть однойменні файли з архіву:
- arena.js
- index.html
- service-worker.js

Збережіть зміни у гілку main і дочекайтеся статусу Ready у Vercel.

В Arena → Кубок ADMIN може додавати гравців до першого зіграного матчу. Наявні пари й команди не змінюються. Нові матчі додаються в кінець сітки: якщо був BYE, його учасник отримує пару з новим гравцем; якщо BYE не було, новий гравець отримує BYE.

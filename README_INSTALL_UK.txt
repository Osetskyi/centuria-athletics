Застосовуйте цей ZIP до наявного репозиторію сайту. Це не повна збірка сайту.

1. Розпакуйте архів.

3. Замініть там index.html та arena.js, додайте arena-history-league-crests-v1376.css.
4. Збережіть усі інші файли проєкту, потім зробіть звичайний commit/push у main. Vercel розгорне репозиторій автоматично.

Не розгортайте цей ZIP або його три файли як окремий проєкт Vercel. Зміна не потребує SQL-міграції.

Centuria Athletics v13.85 — додавання гравців до активного Кубка

У корені репозиторію Osetskyi/centuria-athletics замініть три однойменні файли з архіву:
- arena.js
- index.html
- service-worker.js

Збережіть зміни у гілку main і дочекайтеся статусу Ready у Vercel.

В Arena → Кубок ADMIN побачить кнопку «ДОДАТИ ГРАВЦЯ», доки не зіграно перший матч. Можна вибрати кількох гравців зі списку або вписати ніки вручну. Після додавання учасників жеребкування та сітка Кубка оновляться. Після першого внесеного рахунку або поданого результату додавання закривається.

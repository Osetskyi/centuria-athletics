Centuria Athletics v13.83 — відео для обкладинки Кубка та Ліги

У корені GitHub-репозиторію Osetskyi/centuria-athletics замініть однойменні файли з цього архіву:

- index.html
- arena.js
- app.js
- style.css
- service-worker.js
- arena-league-table-v1232.js
- arena-league-table-v1232.css
- arena-active-event-v1233.js

Збережіть зміни у гілку main і дочекайтеся статусу Ready у Vercel.

Після цього в Arena під час створення Кубка виберіть «ФОТО / ВІДЕО КУБКА». Підтримуються MP4, MOV та WebM до 50 МБ. Відео завантажиться й відтворюватиметься без звуку по колу як обкладинка.

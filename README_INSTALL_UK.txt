Centuria Athletics v13.88 — схема 3-1-4-2

У корені репозиторію Osetskyi/centuria-athletics заміни однойменні файли з цього архіву:
- app.js
- index.html
- service-worker.js
- arena.js

Що змінено:
- схема 3-5-2 у вкладці «Тактика» тепер має розстановку 3-1-4-2: 3 ЦЗ, 1 ЦОП, 2 ЦАПи, ЛП, ПП і 2 форварди;
- додана позиція ЦОП у профілі гравця та сумісність ЦП/ЦОП як альтернативних позицій;
- схема 3-1-4-2 також доступна у складах на збір;
- збереження складів лишається сумісним із поточним обмеженням бази даних;
- збережено попередню правку пар Centuria World Cup з v13.87.

Завантаж ці чотири файли у GitHub замість однойменних, зроби Commit changes у гілку main і дочекайся Ready у Vercel. Потім повністю закрий сайт на телефоні та відкрий його знову.

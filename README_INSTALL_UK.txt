Centuria Athletics v13.89 — схема 3-4-1-2

У корені репозиторію Osetskyi/centuria-athletics заміни однойменні файли з цього архіву:
- app.js
- index.html
- service-worker.js
- arena.js

Що змінено:
- схема 4-4-1-1 замінена на 3-4-1-2: 3 ЦЗ, ЛП, ПП, 2 ЦОПи, ЦАП і 2 форварди;
- схема 3-1-4-2 з попереднього патча залишається у вкладці «Тактика» та у складах на збір;
- позиція ЦОП доступна в профілі гравця, ЦП та ЦОП сумісні як альтернативні позиції;
- збереження складів сумісне з поточним обмеженням бази даних;
- збережена попередня правка пар Centuria World Cup.

Завантаж ці чотири файли у GitHub замість однойменних, зроби Commit changes у гілку main і дочекайся Ready у Vercel. Потім повністю закрий сайт на телефоні та відкрий його знову.
